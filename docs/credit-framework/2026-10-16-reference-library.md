# Glossary and external-reference preview

## Scope

20 manually curated abbreviations, English expansions and Chinese beginner explanations. Search matches abbreviations, aliases, full names and Chinese explanations. Context definitions use only static field/rule metadata, never arbitrary rewriting of user-entered text. Native disclosures work by click, tap or keyboard and sit outside labels. Existing fields and review rules are unchanged.

The source library contains four verified navigation targets: Oney Policy Radar Search, the Oney knowledge library, NAB's business-finance document guide and business.gov.au's business-loan preparation guide. Policy Radar Search opens on Residential; users are explicitly directed to select Commercial. No unsupported deep-link parameter was invented. Primarily residential knowledge content has no case-trigger/domain mapping. General commercial links are mapped by subject for reading only, not eligibility or document requirements.

Oney editorial resources are distinct from primary lender and government sources. Tool summaries are labelled separately from source wording. Link checks are dated 2026-10-16 and are not represented as policy effective dates. Source publication/update dates are unknown unless explicitly supported; the knowledge index's displayed dates are labelled as index/note dates. No lender criteria or numerical policy thresholds were imported.

SBSCH is explicitly historical: ATO states it permanently closed on 1 July 2026. Existing evidence labels remain unchanged; the glossary explains that historical receipts do not imply a currently operating service or a universal document requirement.

## Privacy and maintenance

Static HTTPS anchors use target=_blank, rel=noopener noreferrer and referrerpolicy=no-referrer. No case data is added to URLs. No background fetching, storage, uploads, analytics or synchronisation was added. Search stays in memory. Existing Obsidian/Policy Radar manual review and publication workflow is untouched; this tool only links to its published pages.

Glossary/research helpers are excluded from copy and print reports and applicant checklists. Contextual question references use only the questions already shown in the active tier. Generic domain references explicitly state that they do not establish applicability to the case. Nothing changes ratings, confidence, reviewed evidence or stale-manual protections.

## Verification

Source-check research used primary terminology sources and live Policy Radar navigation. Regression checks cover term matching/aliases, Chinese search, safe text rendering, source metadata, scoped maps, external-link privacy, Simple-tier context, unchanged export text, labels, no storage/network APIs, and print-source exclusions. The existing static URL scan now allows only the exact reviewed URLs in reference-data.js; all other modules remain URL-free except SVG namespace constants.

Browser geometry and native print are not verified: local browser access was connection-refused and protected previews require login. No bypass token was created.
